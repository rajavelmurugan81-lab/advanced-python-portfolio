## 🛠️ Case Study Features in Section 05

1. **Large Walkthrough Viewport:**
   - Highlights `Lab_web_1.png` as the primary uncropped preview.
   - Previous/Next navigation controls with keyboard and click actions.
   - Click to open the uncropped `2225×1252` full-size lightbox viewer.
   - Clean browser header indicating local app protocol and native resolution.

2. **5-Screen Interactive Gallery:**
   - Displays thumbnails for `Lab_web_1.png` through `Lab_web_5.png`.
   - Clicking any thumbnail dynamically switches the main viewport.
   - Includes editable caption slots for each screen.

3. **Connected Evidence Strip:**
   - Direct button to download `website_ppt.pptx` (1.5 MB).
   - Direct button to inspect the physical submission photo (`Bussiness_thesis_audio_rrecording.jpeg`).
   - Direct button to launch the live Web Audio recording sandbox.
